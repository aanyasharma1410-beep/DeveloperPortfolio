## Repository Sections

1. **[Linux/](Linux/)** *(Q1 — CO1)*
   - `system_profile.md`: Workstation hardware specifications table and manual binary/decimal conversions (`75` to binary, `110101` to decimal).
   - `commands_output.txt`: Captured terminal outputs for `ls -la ~`, `ps aux | head -10`, `df -h`, and `free -h`.

2. **[ShellScripts/](ShellScripts/)** *(Q2 — CO2)*
   - `sysinfo.sh` & `sysinfo_output.txt`: Executable Bash script that prints CPU, memory, and top 3 CPU processes.
   - `backup.sh`: Executable Bash script that creates timestamped `.tar.gz` backups inside `~/DeveloperPortfolio_Backups/` and logs every run.

3. **[API/](API/)** *(Q3 — CO3)*
   - `github_profile.json`: Live GitHub user profile fetched via `curl`.
   - `sample_posts.json`: Public posts fetched from JSONPlaceholder.
   - `api_summary.md`: Explanation of REST APIs, HTTP status codes (`200` and `404`), and the `jq` filter breakdown.

4. **[Portfolio/](Portfolio/)** *(Q4 — CO4)*
   - `resume.pdf`: One-page technical resume with education, skills, and project links.
   - `learning_roadmap.md`: Personalised semester-wise learning plan and target certifications.
   - Root `index.html`: Live personal portfolio hosted on GitHub Pages.
